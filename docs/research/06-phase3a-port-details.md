## 1. The 3a/3b seam

**Recommendation (judgment call): port the existing server-HP branches of SafetyEngine and the complete escape coordinator/report guard, with an explicit absent prediction lane.** Merely configuring `preHitPrediction=false` does not remove the dependency graph: the constructor instantiates `DamageLedger`, `HealthPredictor`, and `NativeHealthObserver`; every valid HP sample snapshots both HP models; every NEWTICK calls predictor timing; reset/configuration/status/evidence call all three. Whole-engine porting is behaviorally possible with prediction disabled, but would bring substantial 3b and dropped diagnostic code into 3a. Do not replace these with a fake predictor that silently accepts ON. Document must contain exactly one Object root, not a wrapper/array; Consumable must be explicit. Flags accept only empty text, `true`, `1`; attribute-only nodes are allowed, nested elements are not. Type accepts decimal or `0x` hex, integer 0..0x7fffffff. Positive amounts use a decimal/scientific regex (not hex), finite and >0. [CAT:5-48](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/plugins/auto-drink/catalog.ts#L5-L48)

Only **direct** Activate entries qualify; nested procs/equipment effects, names and SlotType prove nothing. Sum `Heal`/`HealNova` amount into hp, `Magic`/`MagicNova` into mp. `ConditionEffectSelf`/`ConditionEffectAura` with effect exactly `Healing` contributes max duration*1000, bounded (0,86,400,000]; invalid Healing duration rejects the **whole item**, including mixed instant restoratives. Require some hp/mp/HoT and finite totals. Name = trimmed DisplayId, else trimmed Object id, else lowercase `0x${type.toString(16)}`. quickslot = explicit QuickslotAllowed flag. [CAT:50-79](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/plugins/auto-drink/catalog.ts#L50-L79)

Consumed output is `AutoDrinkItem[]`, each row **`{type:number,name:string,hp:number,mp:number,healingDurationMs:number,quickslot:boolean}`**. `autoDrinkCatalog` rejects duplicate types, invalid names/booleans/nonnegative finite values, overlong HoT or all-zero effects, and copies rows before replacing the map. There is no predicted healing, potion fallback ID, or extra item metadata requirement. [DT:14-22](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/auto-drink/AutoDrinkTypes.ts#L14-L22) [DT:66-78](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/auto-drink/AutoDrinkTypes.ts#L66-L78)

## 8. Settings/profile migration

Source Auto Nexus full replay validates enabled (boolean or omitted) and settings (object or omitted), replaces every registered value with supplied value/default, ignores unknown keys/buttons, and defaults absent `PreHitPrediction` to **false**. Missing enabled preserves current enable state. Retired `PredictionModel`, `BurstGuard`, `ReactionWindowMs`, `InstantNexus` are unregistered and disappear on snapshot; partial updates to retired keys fail. Numeric values must be finite numbers (not strings), clamp to declared bounds, retry count truncates; booleans must be booleans. Runtime safetySettings separately normalizes model to v2, burst/instant false, prediction true only for `===true`. [CTX:270-320](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/plugins/PluginContext.ts#L270-L320) [ST:23-37](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/safety/SafetyTypes.ts#L23-L37) [FORK:29-37](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/FORK.md#L29-L37)

Shared automation transactions defer status broadcasts and can roll back both lane configs if either callback/final worker send fails. Source worker validates both configs before installing either and applies drink settings without evaluating before safety gets first evaluation. RT `settings.migrate`/`validate` supplies policy placement but `PluginHost.applyProfile` currently loops through callbacks and applies enabled last, with no worker transaction. Do not send each callback's intermediate configuration. [CTX:323-394](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/plugins/PluginContext.ts#L323-L394) [NW:555-567](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/proxy/network-worker.ts#L555-L567)

**3a Collision HP representation (judgment call): absent, not a persisted hidden false.** There are no existing RT profiles for these plugins. ## 9. Risks, defects, and contradictions to resolve in the plan

1. **Intentional default divergence:** FORK.md and source repeatedly say prediction optional/OFF, including legacy defaults. RT design §3/§6 requires ON starting in 3b. Do not blindly port defaults/banner or absent-key migration. This is the only explicit product-default contradiction in the cited guarantees. [FORK:22-37](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/FORK.md#L22-L37) [AN:101-102](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/plugins/auto-nexus.ts#L101-L102)
2. **Dropping telemetry affects timing, not only presentation:** source `effectiveSettings` uses learned reaction time; removal fixes the 3a normalized reaction default to 400 unless an internal setting is supplied. That changes callback timeout/recovery windows compared with a learned source session. Brief explicitly drops telemetry, so document this as a deliberate simplification, keep bounded retry semantics, and do not claim identical adaptive timing. [NW:119-119](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/proxy/network-worker.ts#L119-L119) [EC:168-203](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/safety/EscapeAttemptCoordinator.ts#L168-L203)
3. **Server maxHP contradiction inside source:** PlayerData.effectiveMaxHealth documentation calls maxHealth a base/stat3 and adds bonuses; actual safety uses stat0 directly and explains the 707→827 double-add defect. Port the safety/controller rule, not that getter/comment. [PD:150-162](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/state/PlayerData.ts#L150-L162) [SE:414-420](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/safety/SafetyEngine.ts#L414-L420) [DC:151-155](https://github.com/DaAwesomePwner/realm-engine-client/blob/88a66b2155cddfe9c1bd086e58d408941dcef697/client/src/auto-drink/AutoDrinkController.ts#L151-L155)
4. **Accepted vs completed vs confirmed:** socket.write(false) means accepted with backpressure; callback means local completion; only a validated accepted RECONNECT starts transition and later Nexus MAPINFO proves arrival. Dropping telemetry must not turn any earlier milestone into “saved”/“arrived”. Keep the accepted shared manual receipt and late-callback ownership rules. 5. **Realtime infrastructure is incomplete:** startup configs would currently be discarded by configureModule before host.start; server-direction write confirmation is absent; cross-module rejected-attempt disarm and own-use filtering need design; profile callbacks can currently expose hybrid settings. These are correctness requirements, not optional polish. `RT src/cli.ts` starts PluginHost before ProxyHost, so startup caching is necessary even in the normal launch path.
6. **Fail-open module exception handling:** RT `session.ts` catches hook errors and passes traffic. Keep original validation at boundaries, prevent/handle serialization errors, make lifecycle hooks nonthrowing, and test invalid configurations. A global `WorkerModule.configure` exception is not wrapped by the same per-session hook catcher in `worker.ts`; validate before mutation and report rejection without crashing the worker.
