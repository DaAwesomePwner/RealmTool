## UI
- The window UI is a quiet instrument panel: graphite neutrals with hairline borders, one signal-blue accent (#6ea8fe) only for the primary action, selected tab and focus, and green/amber/red reserved for live state; a status dot marks only protection, the proxy and plugin states; mono for the log and figures; spacing on a 4px grid, radius 8 for controls and 12 for cards. Why: the user approved this direction over a toned-down violet or an accent-free palette, so protection reads first and the panel stays out of the way while playing. (2026-11-12, unslop-ui, 130d904)
